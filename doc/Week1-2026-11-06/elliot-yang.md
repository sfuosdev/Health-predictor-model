## 2. GitHub Issues

An issue is a task (bug report, assignment, problem...) about a project. It's used to create or discuss tasks that must be done and keep track of whether it's completed.

## 3. GitHub Milestones

A milestone groups related issues together toward a deadline and shows the progress of the group depending on the issues completed.

## 4. Labels Assignees

Labels are tags you stick on an issue to categorize it (bug, documentation, help wanted...), allowing you to label types of issues.

An assignee is the person responsible for an issue where issues are assigned to each member of the group so everyone knows who's responsible for what issue.
