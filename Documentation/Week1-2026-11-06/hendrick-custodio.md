GitHub Issues: Issues are used to raise notice on bugs, ideas, and also to assign specific issues to specific members, as is it serves as a to-do list and discussion board for the repo

GitHub Milestones: A milestones is a group of issue that serve towards a goal, like set "finish prototype" and a due date, and then this will contain related issues that work towards that goal. A progress meter exists to help track progression.

Labels and Assignees: 
* labels are color coded tags that help categorize issues to make it easier to navigate and filter the board, the tags can serve to label things such as what kind of work it is and priority level.
* assignees are members specifically responsible for completing the issue to help organize ownership and accountability
