## GitHub Issues

A GitHub Issue is a place to track a task, report a bug, or suggest an idea. Our team uses Issue #1 to share the Week 1 instructions and ask questions about the assignment.

## GitHub Milestones

A milestone groups related issues under one goal. The Week 1 GitHub Fundamentals milestone helps our team see which tasks are finished and which are still open.

## Labels and Assignees

Labels describe what kind of work an issue involves. For example, the `documentation` label shows that the task involves writing or updating project documents. Assignees are the people responsible for working on the issue.
